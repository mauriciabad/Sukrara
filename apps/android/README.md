# apps/android — Sukrara V1 for Android

Sukrara V1's Android app (Kotlin, newest API generation, GPL header on every file) goes here. It is a clean
rewrite of the PoC in [`poc/spikes/showcase-android`](../../poc/spikes/showcase-android); it reads the shared specs,
schemas and fixtures from [`contracts/`](../../contracts/) and builds the Libre 3 native core from
`third_party/Juggluco` at the repo root (a release build fails without it).

Empty for now.
