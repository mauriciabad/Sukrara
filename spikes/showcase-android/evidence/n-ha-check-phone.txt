Home Assistant (stock "nightscout" integration) → Sukrara's own Nightscout API on the real phone (Pixel 10 Pro,
wearer role, release build 0.1-inv10, source Juggluco). 2026-10-16, branch n-fixes.

Setup (read-only on the phone):
  adb -s 62240DLCH0005W forward tcp:17581 tcp:17581      # phone 127.0.0.1:17581 → Mac 127.0.0.1:17581
  docker run -d --name ha-sukrara -p 8123:8123 -v <scratch>/ha-sukrara:/config ghcr.io/home-assistant/home-assistant:stable
  uv run spikes/nostr/ha_check.py http://host.docker.internal:17581
The container reaches the Mac's forwarded port via host.docker.internal; the phone sees a loopback caller, so no
API secret is needed (api_key left empty in the config flow). LAN mode (with the API secret) was not re-tested here.
